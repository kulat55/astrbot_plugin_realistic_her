# astrbot_plugin_realistic_her

为 AstrBot 虚拟人格补全"真人感"的增强插件。让虚拟人格（例如"林小瞒"）不只是有问必答，而是有自己的生活节奏、小心思和小情绪。

## 功能（16 项）

### 主动类（后台自动触发，她主动来找你）
| # | 功能 | 触发方式 |
|---|------|---------|
| 1 | 失联反应 | 你超过 48 小时没找她，她会带着小情绪先开口 |
| 2 | 反向查岗 | 会话冷下来 3~12 小时，她会反过来问你在干嘛 |
| 3 | 天气感知 | 每天早上主动聊天气（open-meteo 实时数据，无需 key） |
| 4 | 爱好进展 | 她的追剧/看书进度持续推进，隔几天聊一次 |
| 5 | 主动发图 | 随机"随手拍"发图（本地 Stable Diffusion 生图） |
| 6 | 熬夜提醒 | 深夜你还在线，她催你睡觉 |
| 7 | 重要日子 | 你通过 /记住 存的日子，到点她主动提 |
| 8 | 情绪关心 | 你流露不开心后，她隔天主动关心 |

### 对话类（回复后追加，自然的小动作）
| # | 功能 | 表现 |
|---|------|------|
| 9 | 翻旧账 | 随机提起你说过/答应过的事："你上次不是说……" |
| 10 | 吃醋 | 你提到异性/同事/朋友时，她有微妙反应 |
| 11 | 猜你作息 | 按你回复的时段调侃：半夜不睡、午休摸鱼、清晨勤快 |
| 12 | 表情包 | 斗嘴/追加场景偶尔补发一张萌系表情图（预制） |

### 命令类
| 命令 | 说明 | 示例 |
|------|------|------|
| /记住 | 存重要日子，到点主动提 | /记住 11月15日 你要考驾照 |
| /约定 | 存承诺，到点提醒 | /约定 明早8点 叫我起床 |
| /猜拳 | 石头剪刀布 | /猜拳 |
| /真心话 | 她出题问你，或你出题她答 | /真心话 你最近撒谎过吗 |

## 主动消息的"人味"细节
- 每天每个会话最多 2 条主动消息，不会刷屏；
- 读虚拟人生插件（astrbot_plugin_virtual_life）的当日日程，她在"睡觉"时不打扰；
- 15% 概率不发文字改发语音（复用豆包 Seed Audio TTS，配置来自 AstrBot 后台的语音提供商）；
- 文案由 DeepSeek 按"林小瞒"人设生成，口语化、简短。

## 依赖
- AstrBot（星火/其他支持插件系统的版本）
- 本地 Stable Diffusion 生图服务（`http://127.0.0.1:7862/draw`），仅用于主动发图；表情包素材已内置（`images/emotes/`，6 张猫猫表情，随插件分发），不需要生图
- DeepSeek API（读取 AstrBot `cmd_config.json` 里 provider 为 deepseek 的 key）
- 豆包 Seed Audio TTS（可选，用于发语音；没有则全部发文字）
- 虚拟人生插件（可选，仅用于读取"睡觉"时段，避免打扰）

## 安装
1. 将本插件目录放入 AstrBot 插件目录（`core/data/plugins/`）；
2. 重启 AstrBot（或热重载）；
3. 表情包素材已内置，无需额外生成；若素材目录为空且有本地生图服务，插件会后台自动补生成。

## 自定义
`main.py` 顶部有几个常量可按自己环境调整：
- `_CMD_CONFIG`：AstrBot 的 cmd_config.json 路径（默认指向本机实例）
- `_PLANS_FILE`：虚拟人生插件 plans.json 路径
- `_SD_SERVER`：本地生图服务地址
- 苏州天气坐标：`_WEATHER_URL` 里的 latitude/longitude
